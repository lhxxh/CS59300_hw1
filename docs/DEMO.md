# HW1 演示与提交清单

作业截止时间：10 月 10 日晚上 11:59，以课程 Brightspace 的时区和最新通知为准。

## 录屏前

1. 在 `.env` 配置自己的模型服务和 API key，然后运行 `./run.sh`。
2. 打开 http://127.0.0.1:8000 。先真实生成一次总结并提问，确认 key、额度和服务可用。
3. 准备一份可选中文字的论文 PDF。可以运行 `.venv-app/bin/python scripts/verify_live.py` 下载公开示例到 `tmp/pdfs/attention-is-all-you-need.pdf`。
4. 录屏时只展示网页，避免录入 `.env` 或 API key。

## 建议录屏顺序（约 3–5 分钟）

| 步骤 | 操作 | 展示要点 |
| --- | --- | --- |
| 1. 搜索 | 在 Discover 输入 `attention transformer`，点击 Search | 外部 API 返回的标题、作者、年份、摘要和论文链接 |
| 2. 收藏 | 点击 Save paper，再切到 My library | 论文存入本地 SQLite；刷新网页后仍在 |
| 3. 上传 | 上传示例 PDF，展示信息校对窗口后保存 | 自动提取元数据和 15 页正文；可以查看原 PDF 和提取文本 |
| 4. 总结 | 选中上传的论文，进入 Summary，点击 Generate summary | 真实模型生成的问题、方法、证据、局限性与页码引用 |
| 5. 问答 | 进入 Ask AI，问 “What datasets are used? Please distinguish machine translation from constituency parsing.” | 展示英文回答，再点击页码或展开 source passages 核对来源 |
| 6. 持久化 | 重启服务，再打开同一论文 | 论文、总结、问答历史保留 |

同一 PDF 重复上传会复用已有论文；如果之前已经分析过示例，演示时可选另一篇公开论文，或展示重复检测。
